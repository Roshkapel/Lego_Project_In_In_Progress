# Lego_Project_In_In_Progress
Creating a Race Car using SolidWorks CAD software, Project is incomplete but near finished.


The Lego Project uses basic skills learned in the introductory course of mechanical drawing. Techniques such as drawing shapes, approach to drawing, using features and tools for operational effeciency, proper storage methods and descriptions were observed.
The Lego project consists of 201 pieces. Interferences were reduced as much as possible to preserve realistic tolerances but identify potential errors. Only a single drawing of a part is included in this file. 
Some parts were created using excel design table for operational effeciency.
